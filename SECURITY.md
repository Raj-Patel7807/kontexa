# Security Policy

## Reporting Vulnerabilities

If you discover a potential security vulnerability in Kontexa, please report it privately rather than creating a public issue.

You can report vulnerabilities by sending an email to `rajpatel7807@gmail.com`.

Please include:
- A description of the issue and potential impact
- Steps or a proof-of-concept to reproduce the vulnerability
- Any suggested remediations if available

Thank you for helping keep Kontexa secure.
